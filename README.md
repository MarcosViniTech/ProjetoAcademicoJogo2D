# 🎮 O Estudante Universitário

Projeto acadêmico de um jogo 2D desenvolvido na **Godot Engine**, criado com o objetivo de aplicar conceitos de desenvolvimento de jogos, lógica de programação e interação entre elementos em um ambiente virtual.

## 📌 Sobre o projeto

**O Estudante Universitário** é um jogo 2D no estilo plataforma, onde o jogador enfrenta desafios relacionados à vida acadêmica.

O objetivo é sobreviver aos obstáculos encontrados durante a jornada universitária, enfrentando inimigos e coletando itens enquanto avança pela fase.

## 🎯 Objetivos do projeto

- Desenvolver um jogo funcional utilizando a Godot Engine
- Aplicar conceitos de programação e lógica de jogos
- Trabalhar com movimentação, colisões e interações
- Criar uma experiência com interface, fases e desafios

## 🚀 Funcionalidades

- Tela inicial do jogo
- Movimentação do personagem
- Sistema de vida
- Ataques do jogador
- Inimigos com interação e dano
- Sistema de pausa
- Tela de Game Over
- Coleta de itens
- Interface com informações do jogador (HUD)

## 🕹️ Mecânicas

### Personagem
- Movimentação 2D
- Ataque à distância utilizando livros
- Ataque próximo utilizando mochila
- Sistema de dano e vidas

### Inimigos
- Obstáculos inspirados em desafios acadêmicos:
  - ☕ Copo de café
  - 🧟 Cansaço universitário
  - 📄 TCC (chefe final)

### Coletáveis
- 📚 Itens relacionados à rotina de estudos

## 🛠️ Tecnologias utilizadas

- Godot Engine
- GDScript
- Pixel Art / Assets 2D
- Git/GitHub

## 📚 Conceitos aplicados

- Programação orientada a objetos
- Cenas e nós da Godot
- CharacterBody2D
- Area2D
- Colisões
- Animações 2D
- Controle de estados do jogo
- Interface gráfica (HUD)
